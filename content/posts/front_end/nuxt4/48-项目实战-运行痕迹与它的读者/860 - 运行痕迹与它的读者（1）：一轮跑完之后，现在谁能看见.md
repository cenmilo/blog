## 你现在屏幕上有的东西

上一线结束时，你手上有这些：`task_runs` 表里每轮一行、十五个可空的计数格、一条 `10 3 * * *` 的排期。测试一片绿。

现在做一件很简单的事：打开站点，找一个地方看"上一轮几点跑的、几位失败、补了几封信"。找不到——**这张表今天只有写它的那一家，没有任何地方读它**。

这一站不写功能，先把这件事量成读数，再把后面几站的落点一次定完。落点不定，861 写日志、862 开接口、863 做页面就会三家各定一次，最后长成三个互相不一致的形状。

## 四件事，各量一次

跑法只有一条，六档全离线：

```bash
npm run test:unit -- run-surface-baseline
```

### 一、那张表有几个写者、几个读者

```
[痕迹面·读写家数] {"写这张表的":["server/services/task-run.ts"],
"读它的":[],"定义文件":["db/tables/task-runs.ts"],
"服务端引用它的文件":["server/services/task-run.ts"]}
```

`读它的` 那一项扫的是 `server/api/` 与 `app/`，按 drizzle 的符号 `taskRuns` 找（读法只有这一种，按表名找会漏）。结果是空数组。写者一家，读者零家——**这就是整条线的起点**。

### 二、任务这一层成功一轮出不出声

```
[痕迹面·出声] {"任务目录里出声处":[],
"痕迹那一段的出声":["error"],"通知那一段的出声":["error"],
"已有成功出声的文件":["server/api/billing/webhook.post.ts",
"server/utils/http/request-log.ts"],"服务端出声文件总数":10}
```

`server/tasks/` 里一个 `console.` 都没有。但"服务端没人出声"也是错的——一共有十个文件在出声，其中**成功也出声的先例只有两个**，形状都是 `console.log(JSON.stringify({...}))`：一条是每个请求的访问日志，一条是 webhook 入账。

于是 861 要补的那一行有了明确的模板：跟着这两个走，不自创第三种 logger。

### 三、健康检查那一格

```
[痕迹面·健康检查] {"字样命中文件":[],
"server_api第一层":["admin","auth","billing","console",
"count.get.ts","docs", …共 20 项],"像健康的端点":[]}
```

`health` 这个字样在 `server`、`app`、`shared` 三个目录里命中零个文件。它整站不存在，而且这是设计文档里另一句生产面硬指标——**本线不建它**，863 逐句判时点名，别把"后台那一栏能看见"当成"站点健康"。

### 四、卡在发送中的那一行，今天能被问出什么

```
[痕迹面·回收依据] {"有更新列":true,"配置里的时长键":[],
"服务里写死的秒":[],"现在能被问出的数":1}
```

这一条读起来最有意思：**时刻那一列是有的**（`downgrade_notices.updated_at`，非空），所以"这个人卡了多久"读得出来；但 `runtimeConfig` 里没有任何时长键，通知那一路也没有写死的毫秒数。也就是说——分子在，分母没有。

864 要动它，第一件事不是写代码，是回答"多久算死了"这个数从哪来。找不到依据，就改成"只报名单、不动状态"。**随手写一个数，就是把猜测写进跟钱相关的路径上。**

## 六档各钉什么，其中两档是留给后面的报警器

| 档 | 钉住什么 | 到什么时候会红 |
| --- | --- | --- |
| ① | 写者一家、读者零家 | 862 开接口那一刻（那时改名单，不是删这条） |
| ② | 任务层不出声；成功出声只有 `console.log` 那一族 | 861 补日志那一刻 |
| ③ | 健康检查整站不存在 | 有人建 `/api/_health` 时（本线不在计划内） |
| ④ | `requireAdmin` 定义一家、调用者一家；页面侧零个 admin 页 | 863 新开页面时（登记点） |
| ⑤ | 时刻列在、时长出处没有 | 864 找到依据并写进配置时 |
| ⑥ | `server/api/admin/` 下每个端点都必须读 `requireAdmin`；本人面板不许走 admin 档 | 不该红——它是形状纪律 |

⑥ 这条现在绿着，是给 862 准备的护栏：痕迹表记的是"别人的账号被降了"，不属于登录者本人，所以它的读者只能落在 `server/api/admin/` 那一档，不能挂进 `server/api/console/`（那是 `requireUser` 档位，念的是登录者自己的订阅与计量）。新加一个 admin 端点却不走门，⑥ 当场红。

## 判据自己错了四次

这一站真正值得写的部分。四次都不是运行报错，是**绿着读空气**。

第一次，我把"服务端出声的地方"当成两个文件。第一版判据写的是"服务端出声文件必须恰好是 `notify.ts` 与 `task-run.ts`"，跑出来红——实际有十个文件在出声，那两个只是任务那一路的。原来的期望把"这一路"写成了"整个服务端"。改成问两件事：任务目录里出声处为零、服务端出声文件总数大于五（防止识别式失效），中间再按函数体切段各问一次。

第二次，`requireAdmin\(` 认不出定义那一行。源码写的是 `export function requireAdmin (event: H3Event)`，**函数名和左括号之间有一个空格**，式子要求紧挨着的括号，于是定义那家消失了，"两家"被读成"一家"。改成先按符号 `requireAdmin` 找全部提及处，再按文件名把定义处与读者分开。

第三次，找"有没有写死的时长"时把式子铺到整个 `server`，第一下就撞在 `rate-limit.ts` 的 `60 * 1000` 上——那是限流窗口，跟发送中状态毫无关系。范围收到 `server/services/billing` 与 `server/tasks` 两处才对。

第四次最阴。切函数体那段代码用了 `\b` 收尾、又用 `function \w+` 认边界行，**而函数名是中文**：JS 正则里汉字不算单词字符，`\b` 在汉字后面不成立，`\w+` 也匹配不到汉字开头的名字。结果切出来是空串，断言 `[]` 期望 `['error']` 才红了一次——如果我把期望写成"允许为空"，这一档会一路绿下去而什么都没读。现在这两处都改成汉字安全的写法，并在旁边写明为什么不能用 `\b`。

这是这条系列第九次撞上同一条纪律：**判据的覆盖范围只能由撞红量出来**。写完一条判据不打算让它红一次的，等于没写。

## 落点定五条（写进判据文件头，后面不许各定一次）

1. **日志走服务层**：861 那条成功出声写在 `server/services/task-run.ts` 里、绑在写表之后，形状跟现有那两个 `console.log` 一致。库里有行不等于有日志，这两件事分开成立。
2. **接口走 admin 档**：读者落在 `server/api/admin/…`，用 `requireAdmin`。401 与 403 的分工已有实现——没登录 401，登录了角色不够 403，混成一个 401 会让客户端分不清"该去登录"还是"登录了也进不去"。
3. **页面新开目录**：`app/pages/console/` 是本人面板，不是后台。今天 `app/pages` 里 `admin` 字样命中零个文件，所以 863 要新开 `app/pages/admin/`。⚠ 那道门的真实形状是"角色在登录那一刻从会话表 JOIN 出来"，页面门只挡得住"你是谁"，边界仍在接口那一道。
4. **健康检查不在本线**：它是另一句验收，硬塞进来只会让"这一栏看得见痕迹"被误当成"站点健康"。
5. **`sending` 回收要有出处**：见第四节，分子在分母没有。

## 顺手加的账本档

新判据文件如果不进收口那张名单，它跑得再多也不在视野里。所以 `task-run-closure` 加了第 ⑧ 档，专门记第二十三条线的判据文件与档数：

```
[收口·三线账本] {"实际":{"test/unit/run-surface-baseline.test.ts":6},
"缺文件":[],"对不上":[],"永久跳过":[]}
```

它自己也得能被撞红：把期望从 6 改成 99，立刻报 `对不上 ["test/unit/run-surface-baseline.test.ts：6 < 99"]`。上一站那条 ⑦（第二十二条线的账本）读数没动，`⑥` 那份体检的总档数从 43 变成 44。

## 你自己可以量的四件事

- [ ] 你那张"每轮留一行"的表，现在有几个读者？按 drizzle 的符号找，不要按表名找。
- [ ] 你的任务跑成功一轮，进程出不出声？如果不出声，你项目里"成功也出声"的先例是什么形状？
- [ ] 你要新开的读接口，落在哪一档权限？它念的是登录者自己的数据，还是别人的？
- [ ] 有没有一个状态是"抢走了但没落定"？它的时刻列在不在？判定阈值有没有出处？

| 撞到的现象 | 为什么 | 怎么办 |
| --- | --- | --- |
| 判据一路绿，读数却是空数组 | 识别式没匹配上（空格、汉字边界、路径写歪） | 每条判据配一次真变异；再补一条"名单不许为空"的对照 |
| 把"这一路没出声"写成"整个服务端没出声" | 扫描范围与论点范围不一致 | 分开问：目标目录内为零、全局数量作对照 |
| 新接口顺手挂进 `server/api/console/` | 那里现成有例子，最省事 | 先问数据属于谁；⑥ 那条形状纪律会挡 |
| 给卡住的状态写一个超时秒数 | 分子有、分母没有 | 找不到出处就只报名单，不动状态 |
