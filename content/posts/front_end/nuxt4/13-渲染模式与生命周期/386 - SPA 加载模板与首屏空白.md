382 讲过 `ssr: false` 会产出 `<div id="__nuxt"></div>` 的空壳。空着不等于用户该看白板——从浏览器拿到 HTML、到 Vue 挂载好这段时间，得有个东西填。这就是 `spaLoadingTemplate`。

## 它填哪段空白

nuxt-config 里 `## spaLoadingTemplate` 的定义：

> Boolean or a path to an HTML file with the contents of which will be inserted into any HTML page rendered with `ssr: false`.

布尔、或一个 HTML 文件路径；文件内容会被插进**任何以 `ssr: false` 渲染的页面**。365 也提过配套一句：用 `ssr: false` 时应该在 `~/spa-loading-template.html` 放一段 HTML，作为"水合完成前"渲染的加载屏。

## 三种取值

官方列了规则（默认 `null`）：

- **不设（`null`）**：会用某个图层里的 `~/spa-loading-template.html` 文件——前提是它存在。
- **设 `false`**：不加载任何 SPA 加载指示。
- **设 `true`**：去找 `~/spa-loading-template.html`；找不到就用一张 Nuxt 默认图。

要自己写，就在项目里建 `~/spa-loading-template.html`，放一个纯 HTML 片段（比如一个 spinner）：

```html
<div class="loader"></div>
<style>
.loader {
  display: block;
  position: fixed;
  z-index: 1031;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
  width: 18px;
  height: 18px;
  box-sizing: border-box;
  border: solid 2px transparent;
  border-top-color: #000;
  border-left-color: #000;
  border-bottom-color: #efefef;
  border-right-color: #efefef;
  /* ... 一个旋转 loader 的样式 */
}
</style>
```

官方还给了两个 spinner 素材来源：SpinKit、SVG Spinners。注意它是**独立 HTML 文件**、不是 Vue 组件——因为这时候 Vue 还没跑起来，只能是最原始的 HTML/CSS。

## 别和 dev 的加载屏混

nuxt-config 里还有个 `devServer.loadingTemplate`（"Template to show a loading screen"，类型是 function）。那是 `nuxt dev` **启动时**给你看的加载界面，面向开发者、本地用；`spaLoadingTemplate` 是**生产产物首屏**给最终用户看的加载屏。名字像，作用完全不同，别配错地方。

## 什么时候才需要它

只有走 `ssr: false`（纯客户端）才谈得上"首屏空白要填"。走 SSR/预渲染，服务器已经把内容拼进 HTML 了，没有这段空白可填。所以它是 382 那条"`ssr: false` 丢 SEO"之后的补救体验之一：内容终究要等 JS，那就至少别让用户对着一片白。若只是个别块没法服务端渲，官方更推荐 `<ClientOnly>` 局部处理（376），而不是整站 `ssr: false` 再补加载屏。

## 自查

- `spaLoadingTemplate`＝布尔或 HTML 文件路径，内容插进任何 `ssr: false` 渲染的页面，填水合前的空白；默认 `null`。
- 三取值：不设用图层里的 `~/spa-loading-template.html`；`false` 不要加载指示；`true` 找该文件、否则用默认图。
- 它是纯 HTML 文件（此时 Vue 还没跑），不是组件。
- 别和 `devServer.loadingTemplate`（dev 启动加载屏）混。
- 只有 `ssr: false` 才需要它；局部非服务端内容更推荐 `<ClientOnly>`。
