配了 `pageTransition` 却一点动画没有，或切页时控制台报"transition 相关"错误——多半是没搞清 Nuxt 的动画其实是 Vue `<Transition>` 在做事，以及它对页面结构的要求。先讲原理。

## 动画来自 Vue 的 `<Transition>`

官方开头一句定性：

> Nuxt leverages Vue's `<Transition>` component to apply transitions between pages and layouts.

Nuxt 把 `<NuxtPage>` 换页的过程套进 Vue 内置的 `<Transition>`。这个组件的做法是：给进入/离开的元素临时挂上一串 CSS 类（`*-enter-from`、`*-enter-active`、`*-leave-to` 等），你写 CSS 过渡、它就照着播。`mode: 'out-in'` 表示**先播完旧页的离开动画、再播新页的进入动画**（默认就是这个）。

## 由此推出那条硬规则：必须单根元素

因为 Vue `<Transition>` 只能包**一个**根元素，官方用 `::important` 写死：

> Because Nuxt uses Vue's `<Transition>` component, a page or layout you want to animate must have a **single root element**. A page or layout with multiple root elements (a fragment) cannot be animated, so the transition will not run and navigating between routes may error. Nuxt warns about this in development. Wrap the template in a single root element (for example a `<div>`).

想给某个页/布局做动画，它必须只有一个根节点。多根（fragment）动画跑不了、切路由还可能报错，开发期会警告。解法就是用一层 `<div>` 包起来。这和 057 讲的"页面单根元素"是同一条约束，只是动画把它变成硬需求。

## 页面动画：`app.pageTransition`

全局给所有页面加动画：

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  app: {
    pageTransition: { name: 'page', mode: 'out-in' },
  },
})
```

`name: 'page'` 决定 CSS 类前缀，配套在 `app.vue` 写：

```vue
<style>
.page-enter-active,
.page-leave-active {
  transition: all 0.4s;
}
.page-enter-from,
.page-leave-to {
  opacity: 0;
  filter: blur(1rem);
}
</style>
```

四个类名是 `<Transition>` 约定的：`page-enter-active`/`page-leave-active`（动画期间）、`page-enter-from`/`page-leave-to`（起止状态）。

一条 `::note` 提醒：**如果切页的同时还换布局，这里设的页面动画不会跑**——那种情况要设 layout 动画。

## 按页覆盖：`definePageMeta`

给某个页换一套动画，在页面里：

```vue
<script setup lang="ts">
definePageMeta({
  pageTransition: { name: 'rotate' },
})
</script>
```

再写 `.rotate-enter-active` 等对应类名。`name` 变了，**CSS 类名也得跟着改名**（官方 `::warning` 就这句："If you change the `name` property, you also have to rename the CSS classes accordingly."）。

## 布局动画：`app.layoutTransition`

对应 `app.layoutTransition: { name: 'layout', mode: 'out-in' }`，配 `.layout-enter-active` 等类名，管的是布局切换（比如 `/about` 用 `definePageMeta({ layout: 'orange' })` 换了布局）。同样能用 `definePageMeta({ layoutTransition: { name: 'slide-in' } })` 按页覆盖。

## 全局默认与禁用

`pageTransition`/`layoutTransition` 都接受 Vue 的 `TransitionProps`（`name`、`mode` 及其它，需 JSON 可序列化），在 `nuxt.config` 里设全局名：

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  app: {
    pageTransition: { name: 'fade', mode: 'out-in' },
    layoutTransition: { name: 'slide', mode: 'out-in' },
  },
})
```

`definePageMeta` 里的设置**覆盖**全局。要彻底关掉，单页 `definePageMeta({ pageTransition: false, layoutTransition: false })`，或全局 `app.pageTransition: false`。

## JS 钩子与动态方向

高级动效（配合 GSAP 这类库）用 JavaScript 钩子，在 `pageTransition` 对象里给 `onBeforeEnter`、`onEnter`、`onAfterEnter` 等回调——这正是 Vue `<Transition>` 的 JS hooks（`page:transition:finish` 那个 Nuxt 钩子对应它的 `onAfterLeave`，见 371）。

要根据前进/后退用不同动画，用内联中间件改 `to.meta.pageTransition.name`：

```vue
<script setup lang="ts">
definePageMeta({
  pageTransition: { name: 'slide-right', mode: 'out-in' },
  middleware (to, from) {
    if (to.meta.pageTransition && typeof to.meta.pageTransition !== 'boolean') {
      to.meta.pageTransition.name = +to.params.id! > +from.params.id! ? 'slide-left' : 'slide-right'
    }
  },
})
</script>
```

id 变大（往前）用 `slide-left`、变小用 `slide-right`。

## 直接用 `<NuxtPage :transition>`

在 `app.vue` 里也能通过 `transition` prop 就地开：

```vue
<NuxtPage :transition="{ name: 'bounce', mode: 'out-in' }" />
```

但官方 `::note` 提醒：这样设的页面动画**不能再用 `definePageMeta` 在单个页面上覆盖**。

## 自查

- Nuxt 页面/布局动画＝把换页包进 Vue `<Transition>`，靠 `out-in` 与 `*-enter/leave-*` 四组 CSS 类。
- 铁律：要动画的页/布局必须单根元素，多根跑不了还可能报错。
- 两处开关：`app.pageTransition` / `app.layoutTransition`；`definePageMeta` 按页覆盖，换布局时页面动画不跑。
- 改 `name` 要同步改 CSS 类名；JS 钩子做 GSAP 动效；方向不同用中间件改 `to.meta.pageTransition.name`。
