## 四步各留一句

每一步只留一句，句子里放的是这一轮重新跑出来的数（同一条命令：`npm run test:e2e -- test/e2e/no-scripts.spec.ts`，18 passed (49.2s)）。

- **关掉引擎那一步**：四页的脚本面一位都没少——`/` 是 4 个脚本标签、28 条 `modulepreload`、整页 7143 字节、正文可见 354 字，`/docs` 6351／238，`/me` 与 `/console` 各 4528／178；开着引擎那份和关掉那份逐项相等，唯一差的是水合位一真一假；而且那一页仍然取了 42 个 `.js` 文件（开着引擎是 45）。
- **正式开一档那一步**：`/no-js-lab` 的入口模块脚本、全部脚本标签、`modulepreload`、`prefetch` 四项全 0，负载段与 import map 都没有，整页从对照页的 6651 掉到 2750（少 3901），而正文那一句话两页逐字相同；`.js` 请求从 42 条掉到 0 条——不发才是真的不下载。
- **那个标签那一步**：`/`、`/docs`、`/no-js-lab`、`/with-js-lab` 四份 HTML 里 `speculationrules` 出现 0 次，同时同一行报出这三页实际发了哪几类脚本（`application/json`、`importmap`、`module`）；而点向被盖住那一页时，`window` 上的标记还在（`ALIVE`）、`document` 请求 0 条、落地页水合位是真——那一次是客户端路由接管。
- **岛屿那一步**：三页上岛屿根、静态位、`nuxt-client` 位、页面给的 slot 全部在，初始数字 1、3、0 逐位相同；点一遍，对照页 `nuxt-client` 那一位 `3 → 4`，被盖住那页同一位停在 `3`，两边 `pageerror` 都是空数组。

## 判据分档表（按用例数）

这一条线的判据都收在同一个文件里（计划表点名的 `test/e2e/no-scripts.spec.ts`），本轮现跑：

| 是哪一步立的 | 用例数 | 这一档读什么 |
| --- | --- | --- |
| 关掉引擎（第一步） | 5 | 四页脚本面、两种读法并排、下载仍在、配置与产物账、静态岛屿在不在 |
| 开一档（第二步） | 6 | 两页逐项相减、正文不差、下载对照、水合对照、客户端包账、响应头 |
| 那个标签（第三步） | 3 | 四份 HTML 的脚本类型清单＋包内出处、两向到达、预取对照组 |
| 岛屿取舍（第四步） | 4 | 三页内容并排、点了动不动、内联片段并排、第七节那条实验位回归 |
| 合计 | 18 | 全绿 |

整套端到端一起跑是 252 passed／57 skipped／0 failed (56.0s)。这 57 条 skip 不能算过，它们分四类：要库 25、要内容目录读得到 14、要另一趟构建的开关 10、要外部服务变量 8（用 `_research/skip-families.mjs` 读全量日志归的类）。

另外有一档值得单独指出：第四步里那条"回归"读的是另一条线立的岛屿实验位（`3 → 4` 那位），它本轮仍绿 ⇒ 这条线加的两页、那条路由规则，没把别人依赖的那一路改坏。

## 会员区那三条验收，欠的是哪一条

一个生产级会员区在项目开始时立了三句验收标准，这三句现在逐条给结论：

| 那一句 | 现在能不能说"做到了" | 依据 |
| --- | --- | --- |
| 一块数据在渲染期抛错，不许带走整页；红过要留下可读的痕迹 | **闭合** | 错误边界那一站立的 17 条判据（计数位、两条上报口子、控制台不许静音），这条线一次没动它，本轮全绿 |
| 禁 JS 时 islands 区块仍出内容 | **闭合（这条线结案）** | 岛屿那一页内容三处都在、初始数字逐位相同；同时 `nuxt-client` 那一位在 `noScripts` 路上停在初值——两半都有读数 |
| 会员区的数字与数据库里的行数一致 | **仍不能** | 这一句要连着库跑，判据里那 25 条"要库"的用例还空着 |

第三句为什么一直欠着，说清楚比糊过去有用：连库与写库这件事需要一次明确授权，问到这里没有答复；而没有会话就进不了会员区，那两页（`/me`、`/console`）本轮读到的两份 4528 字节其实是同一个未登录分支的形状。所以这条线的读数是公开路由上的读数，不能拿来顶那一句。

## 本机这一版读不到的那几件

这一节开头就说过版本是 nuxt **4.5.2**。四条账本轮重新读了一遍：

- 那个 speculation rules 标签：整包里只有 `nuxt/dist/app/plugins/cross-origin-prefetch.client.js` 一个文件出现这个串，而它是个客户端插件——本身要脚本才跑；`@nuxt/nitro-server/dist` 里 0 处。所以"服务端为被盖住的路由发这个标签"在这一版不可能发生。
- "命中规则的页面整页从客户端包里排除"那句：包里的剔除逻辑挂在应用级开关上（`nuxt/dist/index.mjs:7704`，条件是 `features.noScripts && !dev`），路由级不剔——本轮扫 `.output/public/_nuxt` 读到 81 个 `.js`，两页的代码都在包里。
- 两位开关删的不是同一批东西：`renderer.mjs:142` 把全局位与路由位合成一个判断，但 `:212` 那段入口 `<script>` **只看路由位**。
- 配套的错误码 `E8007`（写的是"路由依赖客户端脚本、上线后被 `noScripts` 静默删掉"）在本机安装包里零命中——那一节的内容比这个版本新。

这四条都按"版本差"记账，不是"官方写错了"。

## 还欠着的，逐条列

一条线收口时最没用的话是"还有一些细节没验"。这一节按四步各自的账，逐条列出来：

**第一步欠的（9 条）**：客户端导航那一次为什么必发一趟请求的成因没分开；`Promise`／thenable 这类值进不进负载没试；`Map`、`Set` 的键是对象时的形状没试；`useRoute()` 在服务端组件里读到 `/` 的机制没追；岛屿内容在客户端导航那一路怎么补没读；会员区两页只在未登录态读过；`$scurrentUser` 的真实形状要库；`noScripts` 与它同页共存时的负载段没读；`/me` 与 `/console` 两份读数完全相同这件事的成因。

**第二步欠的（7 条）**：缓冲渲染那句读不出差别——两份响应都没有 `transfer-encoding`、都有 `content-length`；应用级那一位只读了产物文件，运行时行为没读；关引擎那一趟在 `noScripts` 页上没跑（预期也是 0 条，未验）；`<NuxtLink>` 退化成普通 `<a>` 那句没单测；实验页没进 `/sitemap.xml`，也没站内入口；预渲染与这条规则同时开在哪条路由上没试；两页被打进同一批 chunk 时的包账没细读。

**第三步欠的（6 条）**：speculation rules 那三句（作用域只圈页面路由、`/logout` 不预取、catch-all 放宽）本机无从验；`<NuxtLink>` 预取在本站根本没读到（对照组也是空），所以"没预取"不能算给这条规则；客户端接管那一次页面里的负载形状没追；`page.content()` 读到的是上一跳的 head 这件事，只打印没做成判据；那条"挪位脚本"没在 HTML 里找到；视口过渡那半句没读。

**第四步欠的（6 条）**：`nuxt-client` 那一位靠什么挪位仍不知道；`#hint` 要换成数 DOM 元素才对，现在只是打印；页面给岛屿的 slot 在带脚本那页也不动，这与官方 slot 那句表面冲突（可能要 `selectiveClient: 'deep'` 那趟才见分晓）；`Hydration completed but contains mismatches.` 这条警告出现在两处、成因没分开；被规则盖住那页整段内联岛屿是不是因为走了缓冲，两条未闭合可能是同一件事；799 那一站的形状本轮只做了回归，没重读它的机制。

**跨这两条线之外的旧账**：载荷那一条线收口时列的 10 条（`NUXT_E3004` 运行时没读到、`pick` 进键哈希没测、只注册一半时为什么 `pageerror` 是空的……）原样欠着，加上线上那句"会员区数字与库里条数一致"。

## 自己要复现，最短路径

1. 挑一条公开路由，先按第一步量一份"关掉引擎"的账：脚本标签数、`modulepreload` 条数、正文可见字符、水合位。这一步的作用是让你后面有东西可以相减。
2. 新建一对同形页面，只在路由规则上差一位。别把规则开到别人依赖的路由上。
3. 两页并排读：逐项相减的应该只有那四类；正文、按钮标签、样式那一批发法应该一位不差。
4. 加一块探针组件进去，把"内容在"和"点了动不动"做成两条并列断言，再加一条 `pageerror` 断言。
5. 全程用 `window` 标记＋`document` 请求数判"谁接管了跳转"，别只看地址栏变了没有。
