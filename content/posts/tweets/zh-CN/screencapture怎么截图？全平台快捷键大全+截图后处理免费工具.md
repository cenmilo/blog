截图是每天都要做的事，但很多人还在用"手机拍屏幕"的低效方式。**Windows、macOS、手机都有原生截图能力，记住一两个快捷键就够了**；截完想压缩、标注、做成表情包或 GIF，用免费在线工具顺手完成。本文一表收齐全平台快捷键与后处理流程。

## 一、全平台截图快捷键速查表

| 平台 | 操作 | 效果 |
| --- | --- | --- |
| Windows | `Win + Shift + S` | 框选区域截图（推荐） |
| Windows | `PrtSc` | 全屏进剪贴板 |
| Windows | `Alt + PrtSc` | 只截当前窗口 |
| macOS | `Cmd + Shift + 4` | 框选区域 |
| macOS | `Cmd + Shift + 4` 后按空格 | 截取整个窗口（带阴影） |
| macOS | `Cmd + Shift + 5` | 截图 + 录屏面板 |
| Android | 电源键 + 音量下 | 全屏截图 |
| iPhone | 侧边键 + 音量上 | 全屏截图 |

命令行党补充：macOS 终端里就有 `screencapture` 命令，例如 `screencapture -R 0,0,800,600 out.png` 可按坐标截取区域。

## 二、两个进阶技巧

### 1. 滚动长截图

- Windows：Edge 浏览器 `Ctrl+Shift+S` 支持网页长图；
- 手机（多数国产 ROM）：截图后点"滚动/长截图"按钮，页面自动往下滚；
- 安卓部分机型需第三方 App 配合。

### 2. 截屏录制成 GIF

教程配图比静态截图更直观：

1. 打开 [GIF 制作工具](https://tools.cmdragon.cn/zh)，选择录屏模式；
2. 框选录制区域，完成操作后停止；
3. 直接导出 GIF，无需下载录屏软件。

## 四、常见问题

**Q：Win+Shift+S 截图后找不到文件？** 它默认进剪贴板，需粘贴到聊天窗口或画图里保存；在通知里点开可另存。

**Q：截图截不到受保护内容（如播放器画面）？** 这是 DRM 防拷保护，属正常限制，换用设备自带录屏通常也被同样拦截。

**Q：截图里有隐私信息怎么处理？** 发布前打码或裁剪；含敏感内容的文件建议用 [图片元数据移除](https://tools.cmdragon.cn/zh) 类工具清掉拍摄位置等隐藏信息。
