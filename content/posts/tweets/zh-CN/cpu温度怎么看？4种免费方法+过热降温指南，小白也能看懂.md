玩游戏就黑屏、风扇狂转像起飞？先查 CPU 温度。**查看 CPU 温度有四种免费方法**：Windows 自带任务管理器（Win11 部分机型支持）、重启进 BIOS 看、装免费的监控软件、或者打游戏时用游戏内监测悬浮窗。本文讲清每种操作，并给出"多少度算过热"的判断标准。

## 一、CPU 温度参考区间

| 温度区间 | 状态 |
| --- | --- |
| 30–50℃ | 待机正常 |
| 50–75℃ | 中高负载正常（视频剪辑、游戏） |
| 75–90℃ | 满载偏高，注意散热 |
| 90℃+ | 过热风险，多数 CPU 会降频自保 |

长期超过 85℃ 会加速老化并导致降频卡顿，需要处理。

## 二、四种查看方法

### 方法 1：任务管理器（Win11 最省事）

`Ctrl+Shift+Esc` 打开任务管理器 →「性能」→「CPU」，部分 Win11 机型直接显示当前温度，无需装任何软件。

### 方法 2：进 BIOS/UEFI 看

开机按 Del 或 F2 进 BIOS，硬件状态页会显示 CPU 温度。优点是不受系统影响，缺点是只能看待机温度，看不到负载温度。

### 方法 3：免费监控软件（推荐日常用）

- **HWMonitor / Open Hardware Monitor**：开源免费，显示每个核心的温度、电压、风扇转速；
- **Core Temp**：轻量，常驻任务栏显示实时温度；
- 想开机自启：把软件快捷方式放进"启动"文件夹即可。

### 方法 4：游戏内悬浮窗

游戏加加、MSI Afterburner 等可在游戏画面上叠加温度显示，边玩边看，适合确认"游戏掉帧是不是过热降频"。

## 三、温度过高的 5 条降温措施

1. **清灰**：风扇与散热鳍片积灰是第一元凶，半年到一年清一次；
2. **换硅脂**：使用两三年后导热硅脂干化，重新涂抹可降 5–10℃；
3. **理线与风道**：机箱内线材塞满会阻断风道，抽风方向要顺畅；
4. **检查后台进程**：任务管理器按 CPU 排序，挖矿木马或异常进程及时处理；
5. **笔记本加散热支架**：垫高底部进风，简单有效。

## 四、常见问题

**Q：笔记本待机 70℃ 正常吗？** 偏高。轻薄本负载 70℃ 属正常，但待机就 70℃ 说明后台有高占用进程或需要清灰。

**Q：温度波动很大正常吗？** 正常，CPU 温度随负载秒级波动；判断过热要看"满载稳定值"而不是瞬时峰值。
